# FINZANJIR Frontend

User-facing application layer. UI modules remain separate views over one shared FINZANJIR backend and data flow.

Planned views: Dashboard, Citizen, Human + Case, Synthetic Bank, Signal/Risk, Cross-Bank Fraud, Audit/KPI, FINZANJIR AI, and 16 Layers.


## Current prototype UI

- Responsive FINZANJIR workspace shell using the existing navy primary and complementary teal accents.
- Dashboard plus eight module views, each with its own context/status panel.
- FINZANJIR AI chat connects to the existing grounded `/api/ai/answer` API and displays knowledge references.
- Synthetic Bank runs synthetic scenarios only. Human+Case and Citizen views are explanatory/read-only. Cross-Bank exchange remains disabled.
- The repository does not currently contain an official logo asset; the lettermark is a temporary text treatment, not an official logo reproduction.
